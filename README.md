# Selenium Java Automation Framework

Hybrid Automation Framework developed using:

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model
- Apache POI
- Log4j2
- Allure Reports
- Selenium Grid
- Docker
- Jenkins
- Git and GitHub

## Application Under Test

OrangeHRM Demo Application

## Execution

The framework supports:

- Local execution
- Selenium Grid execution
- Cross-browser testing
- Jenkins CI execution
